EDHR PWA

Upload all files in this folder to the root of a GitHub Pages site or another HTTPS static host. The root index.html is the app entry point.
On Android Chrome choose Install app / Add to Home screen. On iPhone Safari use Share > Add to Home Screen.
For local preview: python -m http.server 8080, then open http://localhost:8080.

Login, registration, job search, resume builder and application handling continue on the official EDHR website.
